# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The full text at that link applies to every space the project uses: issues, pull requests, discussions and review comments.

In short: criticize code and ideas as hard as they deserve, and never the person. No harassment, no personal attacks, no publishing of anyone's private information.

## Reporting

Report a problem to the maintainer, [Ashwin Sathian](https://github.com/AshwinSathian), privately, using the contact on that GitHub profile. Reports are kept confidential. If the report concerns the maintainer, say so in a GitHub issue without details and ask for another contact.

## Enforcement

The maintainer may edit or remove comments, commits and issues that break this code, and may block a contributor temporarily or permanently. The Contributor Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban) are the scale used.
